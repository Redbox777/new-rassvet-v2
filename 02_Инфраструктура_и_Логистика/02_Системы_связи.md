# Системы связи

## 1. TRL 1-2: Простые системы

### Голубиная почта

**Обучение голубей:**
1. Взять птенцов из гнезда (возвратный инстинкт)
2. Постепенно увеличивать расстояние
3. Максимальная дальность: 500-800 км
4. Скорость: 60-100 км/ч

**Содержание:**
- Голубятня (защита от хищников)
- Корм (зерно, вода)
- Метки (кольца на лапы)

**Сообщения:**
- Капсула (лёгкая, водонепроницаемая)
- Записка (тонкая бумага)
- Максимум: 5-10 грамм

### Семафорная связь

**Принцип:** Визуальная передача сигналов

**Оборудование:**
- Флаги (2 шт, 40×40см)
- Мачта (5-10м высота)
- Кодовая книга

**Дальность:**
- День: 5-10 км (наблюдатель с биноклем)
- Ночь: фонари/костры (3-5 км)

**Скорость:** 5-10 слов/минуту

### Оптический телеграф (шапп)

**Конструкция:**
- Башня (высота 10м)
- Подвижные балки (2 шт)
- Система тросов и блоков

**Кодирование:**
- Позиции балок = буквы/слова
- Кодовая книга у операторов

**Дальность:** 10-15 км между станциями

## 2. TRL 3: Электрическая связь

### Электрический телеграф

**Принцип:** Электрический ток по проводу

**Компоненты:**
- **Провод:** Медный (1-2 мм)
- **Изоляторы:** Керамические/стеклянные
- **Столбы:** Деревянные (50м интервал)
- **Батарея:** Вольта/Даниэля
- **Ключ Морзе:** Для передачи
- **Приёмник:** Электромагнитный

**Азбука Морзе:**
- Точка (короткий сигнал)
- Тире (длинный сигнал, 3 точки)
- Буквы: комбинации точек и тире

**Скорость:** 20-30 слов/минуту

**Строительство линии:**
1. Установка столбов (глубина 1м)
2. Крепление изоляторов
3. Натяжка провода (не провисать!)
4. Заземление (на концах)

### Телефон (TRL 4)

**Принцип:** Звук → электричество → звук

**Компоненты:**
- Микрофон (угольный)
- Телефонная трубка
- Батарея (питание микрофона)
- Звонок (вызов)

**Дальность:** До 20 км (без усилителей)

## 3. TRL 4: Радиосвязь

### Азбука Морзе по радио

**Оборудование:**
- Передатчик (искровой/ламповый)
- Приёмник (детекторный/регенеративный)
- Антенна (длинный провод)
- Ключ Морзе

**Диапазоны:**
- КВ (3-30 МГц): дальней связь
- УКВ (30-300 МГц): местная связь

**Дальность:**
- КВ: сотни-тысячи км (ионосфера)
- УКВ: 10-50 км (прямая видимость)

### Голосовая связь (рации)

**Требования:**
- Лампы/транзисторы
- Модуляция (AM/FM)
- Антенны
- Питание (аккумуляторы)

## 4. Сигнализация

### Звуковая:
- **Колокол:** Дальность 2-3 км
- **Рог/горн:** 1-2 км
- **Выстрелы:** 3-5 км

### Визуальная:
- **Костры:** Ночь, 5-10 км
- **Дым:** День (мокрая трава), 5 км
- **Зеркало (гелиограф):** День, 10-20 км

## 5. Коды и шифры

### Простые коды:
- **Цезарь:** Сдвиг букв на N позиций
- **Книжный шифр:** Страница/строка/слово

### Надёжные:
- **Одноразовый блокнот:** Случайные ключи
- **Кодовые слова:** Для частых сообщений

## 6. Предостережения
- [!] Линии связи — приоритетная инфраструктура
- [ ] Резервные каналы (голуби + телеграф)
- [ ] Защита от прослушивания (шифры)
- [ ] Регулярная проверка оборудования
