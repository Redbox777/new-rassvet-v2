# 🌅 Новый Рассвет v2.0

**Открытая модульная база знаний для построения устойчивой цивилизации**

---

##  Миссия проекта

Создание проверенной, структурированной и открытой базы знаний, которая позволит восстановить цивилизацию с нуля — от агротехники и базовых материалов до ториевых реакторов и купольных сооружений.

## 📚 Структура базы знаний

Проект разделён на **11 тематических модулей**, каждый из которых содержит документы с указанием:
- **TRL** (уровень технологической готовности: 1–5)
- **Зависимостей** (что нужно иметь перед началом)
- **Ссылок на CAD-модели** (параметрические чертежи FreeCAD/STEP)
- **Научных и исторических источников**
