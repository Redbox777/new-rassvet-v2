## Список моделей

| Код | Название | TRL | Форматы | Описание |
|-----|----------|:---:|---------|----------|
| NR-AGR-001 | Компостер Джонсона | 2 | .FCStd, .STEP | Трёхкамерный компостер с вентиляцией |
| NR-AGR-002 | Высокая грядка стандарт | 1 | .FCStd, .STEP | Деревянный короб 1.2x2.4м |

## Стандарт именования
`NR-[КАТЕГОРИЯ]-[НОМЕР]_[Название]_v[Версия].[Расширение]`

## Форматы файлов
- **.FCStd** - родной формат FreeCAD (параметрический, с историей)
- **.STEP** - универсальный формат для импорта в другие CAD
- **.SVG** - 2D чертежи для лазерной резки
