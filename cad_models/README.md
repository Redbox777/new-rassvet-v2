# 📐 Реестр инженерных моделей (CAD)

Этот каталог содержит параметрические 3D-модели и чертежи для проекта "Новый Рассвет".

## Стандарты именования файлов
`NR-[КАТЕГОРИЯ]-[НОМЕР]_[Название]_v[Версия].[Расширение]`

## Каталог моделей

### 🌾 Сельское хозяйство (02_Agriculture)
- **NR-AGR-001**: Компостер Джонсона (3-камерный)
- **NR-AGR-002**: Высокая грядка (1.2×2.4м)
- **NR-AGR-003**: Система сбора дождевой воды
- **NR-AGR-004**: Дуговой парник с биоподогревом
- **NR-AGR-005**: Компостный туалет (торфяной)

### 🏗️ Строительство (03_Construction)
- **NR-CON-002**: Столярный верстак
- **NR-CON-004**: Сыродутный горн (блумерия)
- **NR-CON-005**: Геодезический купол 2V (Ø6м)
- **NR-CON-006**: Русская печь (базовая)
- **NR-CON-007**: Баня (каркасная)

### ⚡ Энергетика (01_Energy)
- **NR-ENR-003**: Ветрогенератор 12В (400Вт)

## Форматы
- **.parametric.md** - текстовое описание параметров, материалов и инструкций
- **.svg** - 2D чертежи для быстрой визуализации
- **.FCStd / .STEP** - (добавляются по мере создания в FreeCAD)
